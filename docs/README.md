# OctoAcme Project Management Docs

Welcome to the OctoAcme Project Management Docs! This README provides an overview and entry point to our standardized project management process documents for delivering projects at OctoAcme.

## Project Management Process Summary

OctoAcme uses an iterative and collaborative project management approach based on clear roles, data-driven decisions, and stakeholder alignment. Key practices include:

- **Iterative delivery** with regular demos and feedback loops
- **Clear project ownership** with a named Project Manager and Product Lead per project
- **Documented lifecycle** from initiation, planning, execution, release, to retrospective
- **Well-defined artifacts** including project charters, backlog items, risk registers, and checklists
- **Regular communication cadence** with standups, weekly syncs, and stakeholder updates
- **Cross-functional collaboration** with defined interaction patterns between roles
- **Emphasis on psychological safety** and continuous improvement
- **Data-informed decisions** measured through success metrics and retrospectives

## Key Artifacts Across Phases

| Artifact | Owners | Primary Use |
|----------|--------|-------------|
| **Project One-pager** | PdM + PM | Problem, goal, success metrics, stakeholders, timeline, risks, team |
| **Backlog & User Stories** | PdM (prioritization) + Team (refinement) | Scoping work and acceptance criteria |
| **Risk Register** | PM + Team | Tracking and escalating risks and dependencies |
| **Release Plan & Milestones** | PM + PdM | Sequencing deliverables and managing timeline |
| **Definition of Done** | Team (lead by PM) | Quality standards and acceptance criteria |
| **Design Specs & Component Library** | UX Designer + Developers | Consistent UI/UX and implementation guidance |
| **Release Notes** | Release Manager + PdM | Communicating changes and known issues |
| **Retrospective Notes & Action Items** | PM + Team | Capturing learnings and driving improvements |

## Communication Cadence

- **Daily**: Team standup (15 min)
- **Weekly**: PM + PdM sync, Risk review, Stakeholder update (if needed)
- **Sprint/Iteration**: Planning, Demo, Retrospective
- **As needed**: Design reviews, escalations, incident response
